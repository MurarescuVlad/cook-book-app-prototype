Behavior notes

  • No backend: favorites and the shopping list persist in localStorage; all recipe data comes from the TheMealDB API.
  • “Recipe of the day” is a random recipe, fetched on every visit to the home page.
  • Shopping-list items are grouped by the recipe they came from; the same ingredient added from two recipes stays in two groups.
  • Header badges read the same stores, so they update live on every page.
  • The category filter is client-side only; the search page queries the API by recipe name.
  • Page titles follow “Title – CookBook” (e.g. “Pasta alla carbonara – CookBook”).
  • Favorite state is shared: the heart on the recipe card, the recipe page button and the favorites page all reflect one store.
